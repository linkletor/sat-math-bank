# SAT Math Bank

A practice site for Digital SAT Math.

Every question here is **originally written and symbolically verified** — each
item's answer is independently re-derived with SymPy from the mathematics as
printed, and any item whose key disagrees is discarded. No College Board
content is reproduced.

The site is a single self-contained HTML file: no server, no build step, no
tracking, no network calls. Open `index.html` anywhere.

The generator that produces the questions is not part of this repository.
